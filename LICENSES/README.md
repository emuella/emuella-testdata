# Licence references

The tracked repository currently contains only Apache-2.0 material; the full
text is the root `LICENSE`.

Files named `LicenseRef-*` summarize where a non-standard or externally hosted
set of terms applies to a manifest. They are not substitute licences, legal
opinions, or grants by Emuella. Users must read and retain the authoritative
upstream terms before acquiring or redistributing a pack.

Standard SPDX identifiers in manifests refer to the corresponding published
licence text. When a third-party pack is materialized, its own licence and
attribution files must remain with it.
